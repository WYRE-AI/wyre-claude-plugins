# Apply the signature in mail clients

After generating HTML, tell the user to copy the **rendered** rich
signature when possible (paste from a browser preview or from the agent’s
HTML rendered in a temp file). Pasting the raw source tags into some
editors shows markup instead of the signature.

## Outlook on the web (and new Outlook)

1. Settings → Accounts → Signatures.
2. New signature → name it (for example “WYRE”).
3. Click into the editor and paste (Ctrl+V / Cmd+V).
4. Set it as default for new messages and replies, then Save.

## Outlook desktop — Windows (classic)

1. File → Options → Mail → Signatures…
2. New → name it.
3. Click into the edit box and paste (Ctrl+V).
4. Choose it under “New messages” and “Replies/forwards”, then OK.

Tip: if paste looks wrong, open the example `.html` in a browser, select
the signature, copy, then paste into the Outlook editor.

## Outlook desktop — Mac

1. Outlook → Settings → Email → Signatures (wording varies slightly by
   build: look under Preferences / Signatures).
2. Create a signature, paste into the body.
3. Assign it to the account for new mail and replies.

Same browser-select-copy fallback as Windows if the rich paste strips
images.

## Gmail

1. Settings (gear) → See all settings → General.
2. Signature → Create new → paste into the editor.
3. Set defaults for new emails and replies / forwards.
4. Save Changes at the bottom of the page.

## Apple Mail (bonus)

1. Mail → Settings → Signatures.
2. Select the account, click +, paste into the body.
3. Leave “Always match my default message font” **unchecked** so styling
   is preserved.
4. Drag the signature onto the account if it landed under All Signatures.
